# NEXORA — Admin Dashboard UI Kit

A modern, responsive **Admin Dashboard UI Kit** built with semantic HTML, modular CSS, and vanilla JavaScript.

NEXORA is designed as a reusable front-end foundation for dashboards, SaaS products, CRM/ERP systems, e-commerce platforms, finance tools, project management systems, and internal business applications.

## ✨ Highlights

- Responsive desktop, tablet, and mobile layouts
- Light and dark theme support
- RTL/LTR-ready interface
- Dashboard and analytics views
- E-commerce pages and product management
- Customers, users, contacts, and CRM-oriented screens
- Orders, invoices, transactions, and finance pages
- Projects and Kanban workflow
- Calendar, chat, and email interfaces
- File manager
- Search and command-palette interactions
- Notifications, modals, toasts, and reusable UI components
- Authentication screens and account/settings pages
- Error and maintenance pages
- Modular CSS and JavaScript architecture
- No framework or build step required

## 🚀 Getting Started

No build process is required.

1. Clone or download the repository.
2. Open `index.html` in a modern browser.
3. Explore the dashboard and individual pages.

For local development, using a simple static server is recommended.
