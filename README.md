# NEXORA — Admin Dashboard UI Kit

A modern, responsive **Admin Dashboard UI Kit** built with semantic HTML, modular CSS, and vanilla JavaScript.

NEXORA is a reusable front-end foundation for SaaS platforms, CRM/ERP systems, e-commerce applications, finance tools, project management software, and internal business dashboards.

## ✨ Features

* Responsive layouts for desktop, tablet, and mobile
* Light and dark theme support
* RTL/LTR-ready interface
* Dashboard and analytics views
* E-commerce and product management pages
* Customer, user, contact, and CRM-oriented interfaces
* Order, invoice, transaction, and finance pages
* Project management and Kanban workflow
* Calendar, chat, and email interfaces
* File manager
* Search and command-palette interactions
* Notifications, modals, toasts, and reusable UI components
* Authentication screens and account settings
* Error and maintenance pages
* Modular CSS and JavaScript architecture
* No framework or build step required

## 🛠️ Tech Stack

* **HTML5** — Semantic page structure
* **CSS3** — Styling, layouts, and responsive design
* **Vanilla JavaScript (ES6+)** — UI interactions and application behavior
* **JavaScript-based utilities** — Interactive dashboard components and data visualization

## 🚀 Getting Started

NEXORA does not require a build process.

1. Clone or download this repository.
2. Open `index.html` in a modern web browser.
3. Navigate through the dashboard and available pages.

For local development, a simple static web server is recommended.
